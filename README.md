# Abdur Rahman Khan — Portfolio
 
A personal portfolio website showcasing my work across DevOps engineering, cloud computing, ethical hacking, and full-stack software development. Built as a fast, modern, and fully responsive single-page application.
 
**Live site:** [portfolio-arkmfk.vercel.app](https://portfolio-arkmfk.vercel.app)
 
---
 
## About This Project
 
This portfolio presents my background as a Computer Science undergraduate with hands-on experience across DevOps, cloud platforms, ethical hacking, and multi-language software development. It highlights shipped projects, technical certifications, core skill domains, and ways to get in touch — all in a clean, recruiter-friendly format designed for international job applications.
 
## Features
 
- **Home** — Introduction, role highlights, and quick stats
- **About** — Background, core domains, and working philosophy
- **Projects** — Featured engineering projects with direct links to source code
- **Skills** — Technical competencies across languages, frameworks, and tools
- **Tools & AI** — Development tools and AI-assisted workflows used day to day
- **Certifications** — Verified credentials from AWS, Google Cloud, Microsoft, IBM, and other platforms
- **Contact** — Direct ways to connect via email, GitHub, and LinkedIn
- Dark/light theme toggle
- Fully responsive layout across mobile, tablet, and desktop
- Smooth scroll reveal animations and polished micro-interactions

## Getting Started
 
### Prerequisites
 
- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (or your preferred package manager)
### Installation
 
```bash
# Clone the repository
git clone https://github.com/AbdurRahmanKhan000/<repository-name>.git
 
# Move into the project directory
cd <repository-name>
 
# Install dependencies
npm install
 
# Start the development server
npm run dev
```
 
The site will be available at `http://localhost:3000` (or the port shown in your terminal).
 
### Build for Production
 
```bash
npm run build
```
 
The production-ready output will be generated for deployment.
